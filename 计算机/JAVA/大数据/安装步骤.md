##### 如果访问webui发现datanode不足3个
```shell
# 三个slave上执行，会删除slave上的数据并重新生成storageID和datanodeUuid，谨慎运行，建议先在VMware进行快照再运行以下命令

- 在未关闭HDFS的情况下，直接关闭虚拟机，导致datanode之间不同步

    <id>aliyunmaven</id>

  </mirror>
</mirrors>
```
