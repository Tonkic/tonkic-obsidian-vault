### 定义
闭包（Closure）是指一个“内部函数”不仅能干自己的活，还能记住并访问它“外部函数”里的变量，即使那个外部函数已经执行结束了。

### 要求
函数里面嵌套函数
满足3条件：
1. 存在函数的嵌套关系
2. 内层函数引用了外层函数的变量
3. 外层函数返回内层函数的地址值

### 例子
```python
def counter_outer(start):  # 外层函数
    count = start          # 外层函数的局部变量

    def inner():           # 条件1：存在函数的嵌套关系
        nonlocal count
        count += 1         # 条件2：内层函数引用了外层函数的变量
        return count

    return inner           # 条件3：外层函数返回内层函数的“地址值”（也就是函数名/对象）
```
