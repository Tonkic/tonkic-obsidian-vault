### 目的
在不修改原函数的情况下添加新功能

### 例子
```python
def timer(func):          # 1. 接收一个函数作为参数（原手机）
    def wrapper():        # 2. 在内部定义一个外壳函数（手机壳）
        start = time.time()
        func()            # 3. 真正执行你的原函数（原手机核心功能）
        end = time.time()
        print(f"耗时: {end - start:.4f} 秒")
    return wrapper        # 4. 把包装好的新函数丢出去（套好壳的手机）

@timer  # 这一行等价于：download_file = timer(download_file)
def download_file():
    print("正在下载大文件...")
    time.sleep(1.5)
    print("下载完成！")

# 直接调用，自动带上了计时功能
download_file()
```

添加装饰器，需要：
1. 存在[闭包](闭包.md.md)
2. 存在需要被装饰的函数
