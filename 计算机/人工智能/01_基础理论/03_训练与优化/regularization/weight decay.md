一、左图：验证损失 vs 训练损失（不同 weight decay）
- 每个点是一段训练的结果，不同颜色代表不同的 AdamW weight decay（例如 0.0 / 0.1 / 0.3）。
- 所有点基本落在一条直线上：训练损失越低，验证损失也等比例降低，各个 weight decay 几乎没有分叉。
- 结论：在这些 LLM 实验里，weight decay 并不是通过“减少过拟合”来起作用的——它没有明显改变训练/验证之间的泛化差距。也就是“用 WD 不是为了控制过拟合”。

二、中图：10× 余弦学习率衰减（cosine LR decay）下的训练损失
- 横轴是迭代步，纵轴是训练损失。采用较强的余弦 LR 衰减（峰值到末尾大约 10× 的变化）。
- 现象：
    - 不用 WD 的曲线更高、下降更慢，后期容易“跑不动”或平台期。
    - 适当 WD（如 0.1/0.3）能明显把曲线压低，后期仍能持续优化。
    - 将一部分“尺度不变（scale-invariant）”的参数使用极小学习率（图例里的 “w_tiny LR”）时，即便不加 WD，也能取得与加 WD 类似的效果。
- 解释机制（要点）：
    - Transformer 中大量权重处于 LayerNorm 之下，模型对它们的“整体缩放”不敏感（尺度不变）。这类权重的范数在训练中会逐步变大，从而把“有效步长”压小（有效步长近似 ∝ LR / ||w||）。
    - 余弦衰减已让 LR 变小，如果再叠加权重范数变大，有效步长会被“双重变小”，训练后期就更难继续优化。
    - Weight decay 会持续把权重往 0 拉，抑制范数增长，从而维持较大的有效步长；或者，直接给这类尺度不变参数用“极小 LR”，也能达到类似效果。
    - 因此，在带有强 LR 衰减（如 cosine）的日程下，WD 与 LR 强烈耦合，WD 的收益显著。

三、右图：恒定学习率（constant LR）下的训练损失
- 当 LR 保持常数时，各曲线差距明显缩小；用或不用 WD、或给尺度不变参数用极小 LR，最终曲线更接近。
- 含义：WD 的主要收益是在“LR 随时间衰减”的训练中显现；当 LR 不衰减时，权重范数增大会降低有效步长，但因为基础 LR 一直较大，这个影响不至于让训练后期停滞，因此 WD 的相对价值变小。




l2 是 先加入正则项 loss 然后计算梯度更新量；

weight decay是先 计算梯度更新量 然后简单的进行权重衰减，即简单地对更新后地权重进行 (1-weight_decay_ratio)的 放缩。

二者在sgd下等价，在其它复杂的optimzier下不等价。
