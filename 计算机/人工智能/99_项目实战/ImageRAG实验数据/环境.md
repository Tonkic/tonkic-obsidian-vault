### 1. 创建并激活基础环境

使用 Python 3.10 以获得最佳的库兼容性（特别是针对 `flash-attn` 和 `sam2`）。

Bash

```
conda create -n TACMGR python=3.10 -y
conda activate TACMGR
```

### 2. 安装 PyTorch (核心步骤)

我们选择 **PyTorch 2.5.1 + CUDA 12.4**，这是目前支持 FLUX 和 Qwen2.5-VL 最稳定且性能最好的组合。

Bash

```
# 安装 PyTorch 生态
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
```

### 3. 安装 Flash Attention 2 (性能关键)

为了让 FLUX 和 ColQwen 全速运行，必须正确安装此库。 _注意：这步需要编译，可能需要几分钟。_

Bash

```
# 预先安装构建依赖
pip install psutil ninja packaging


# 安装 Flash Attention
pip install flash-attn --no-build-isolation
```

### 4. 安装核心依赖库 (FLUX & ColQwen)

安装 Diffusers、Transformers 以及项目所需的图像处理库。

Bash

```
# 基础工具与图像处理
pip install numpy pandas tqdm pillow opencv-python scipy einops protobuf sentencepiece

# AI 核心库 (FLUX & ColPali 依赖)
pip install --upgrade diffusers transformers accelerate huggingface_hub tokenizers

# ColPali 引擎 (用于 ColQwen2.5)
pip install colpali-engine

# OpenAI & CLIP (用于旧代码兼容及 TAC 调用)
pip install openai openai-clip
```

### 5. 安装 Grounded SAM 2 相关库 (TAC 增强)

这两个库通常不在 PyPI 上发布最新版，建议直接从 GitHub 源码安装以确保包含最新的模型定义。

Bash

```
# 1. 安装 Grounding DINO (目标检测)
pip install git+https://github.com/IDEA-Research/GroundingDINO.git

# 2. 安装 SAM 2 (图像分割)
pip install git+https://github.com/facebookresearch/segment-anything-2.git

# 3. 辅助库 (Grounded SAM 2 常用)
pip install supervision pycocotools
```
