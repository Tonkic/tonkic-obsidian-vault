#  迁移学习 (Transfer Learning) 路径分类

迁移学习是利用在一个任务上预训练好的模型来解决另一个相关任务的技术。在大模型领域，它主要表现为三种形式：

- **Transfer Learning (冻结主体，训练头部)**：
    - **操作：** 冻结预训练模型的全部核心网络层（如 Transformer 编码器或卷积层），只训练自己定制的**全连接层或任务分类层** (Head)。
    - **特点：** 训练成本极低，但模型在新任务上的表现提升有限。

- **Extract Feature Vector (特征提取器)**：
    - **操作：** 先用预训练模型的主体网络层，计算出所有训练和测试数据的**特征向量**（Embedding），然后**抛开**预训练模型，只训练一个**简配版**的外部网络。
    - **特点：** 速度快，无需微调原模型，将 LLM 视为静态编码器。

- **Fine-tuning (微调)**：
    - **操作：** **解冻**预训练模型的部分或全部网络层，并用新数据进行训练。这是最常见的大模型定制路径。

## Fine-tuning (微调) 的两种主要划分

微调路径可以进一步按不同的维度划分：

### 维度一：按**训练参数量**划分

Fine-tuning 根据需要更新的参数量，分为全量和高效两种：

| 子类       | 全称                                           | 训练参数量               | 优势                | 主要问题 (FFT)                                       |
| :------- | :------------------------------------------- | :------------------ | :---------------- | :----------------------------------------------- |
| **FFT**  | **Full Fine Tuning (全量微调)**                  | **全量参数**（与预训练时一样多）  | 在特定数据领域表现最好       | 1. 训练成本极高 2. **灾难性遗忘** (Catastrophic Forgetting) |
| **PEFT** | **Parameter-Efficient Fine Tuning (参数高效微调)** | **部分参数**（仅占全量的极小比例） | 成本低、效率高，有效缓解灾难性遗忘 | 是目前主流且通用的微调方案 (如 LoRA、QLoRA 等)                   |

### 维度二：按**训练数据来源及方法**划分

Fine-tuning 根据所使用的训练数据类型和方法论，分为以下技术路线：

| 路线 | 全称 | 训练数据来源 | 核心方法 | 目标 |
| :--- | :--- | :--- | :--- | :--- |
| **SFT** | **Supervised Fine Tuning (监督式微调)** | **人工标注**的“输入-期望输出”数据 | 监督学习 | 让模型**学会遵循指令**，执行特定任务。 |
| **RLHF** | **Reinforcement Learning with Human Feedback (基于人类反馈的强化学习)** | **人类反馈**（偏好排序） | 强化学习 (RL) | 将人类的**偏好和价值观**引入模型，实现更好的**对齐 (Alignment)**。 |
| **RLAIF** | **Reinforcement Learning with AI Feedback (基于AI反馈的强化学习)** | **AI模型反馈**（代替人类排序） | 强化学习 (RL) | 解决收集人类反馈的**成本和效率**问题，快速实现模型对齐。 |
